# Промежуточные результаты: дообучение ruBERT для NER

## 1. Что сделано

Выполнено дообучение модели `DeepPavlov/rubert-base-cased` для задачи NER (token classification) на русскоязычных инвестиционных новостях.

Целевые типы сущностей (классы NER):
- `Company` — **Компания**: организации, эмитенты, бренды (`Сбербанк`, `Apple`, `Роснефть`).
- `Index` — **Индекс**: биржевые индикаторы (`Индекс МосБиржи`, `S&P 500`).
- `Event` — **Событие**: финансово-экономические события (`дивиденды`, `IPO`, `повышение ставки`).
- `Commodity` — **Сырьё**: товарные активы (`нефть`, `Brent`, `золото`, `газ`).
- `Currency` — **Валюта**: валюты и денежные обозначения (`руб`, `USD`, `$`).
- `Person` — **Персона**: физические лица (`Илон Маск`, `Олег Казанов`).
- `Location` — **Локация**: страны/города/регионы (`Россия`, `США`, `Ангола`).
- `Sector` — **Сектор**: отрасли экономики (`банковский`, `телеком`, `IT`).
- `Time` — **Время**: даты и периоды (`2025`, `IV квартал`, `в декабре`).

---

## 2. Данные и протокол

Использованы датасеты проекта:
- train-разметка: `data/labeled/ner_entity_dataset.csv` (`11278` строк)
- независимый test/holdout: `data/test/test_ner_dataset.csv` (`858` строк)

Контроль пересечений train/test выполнен отдельно, утечек нет:
- `overlap_exact_count = 0`
- `overlap_pattern_count = 0`

Как готовились данные:
1. Исходный корпус: `Kasymkhan/RussianFinancialNews`.
2. Очистка текстов (HTML/URL/спецсимволы, нормализация пробелов).
3. Формирование NER-схемы:
   `sample_id, news_id, published_at, source, title, context, entity, entity_type, start_char, end_char`.
4. Разделение:
   - train для обучения,
   - независимый holdout только для финальной оценки.

## 3. Как обучалась модель ruBERT

Эксперимент: `data/experiments/hf_rubert_base_ner_v2_cpu/`

Параметры:
- модель: `DeepPavlov/rubert-base-cased`
- `epochs = 8`
- `batch_size = 4`
- `learning_rate = 2e-5`
- `weight_decay = 0.01`
- `warmup_ratio = 0.1`
- `max_length = 256`
- `stride = 96`
- балансировка train: включена (`--balance-train`)
- устройство: `CPU`

Этапы обучения:
1. Загрузка train-разметки (`11278` строк) и группировка в документы/контексты.
2. Внутренний split train/valid:
   - `train_docs = 10521` (после балансировки),
   - `valid_docs = 889`.
3. Постановка задачи: token classification с BIO-тегами.
4. Обучение 8 эпох с валидацией по `eval_f1`.
5. Выбор лучшего чекпоинта и финальная проверка на независимом test (`858` примеров).

## 4. Метрики и их смысл (test/holdout)

Агрегированные метрики:
- `accuracy = 0.9627`
- `precision_macro = 0.8975`
- `recall_macro = 0.8503`
- `f1_macro = 0.8727`
- `f1_weighted = 0.9772`

Формулы:
- `Precision = TP / (TP + FP)`
- `Recall = TP / (TP + FN)`
- `F1 = 2 * Precision * Recall / (Precision + Recall)`
- `Accuracy = (TP + TN) / (TP + TN + FP + FN)`
- `Macro-F1 = (1/K) * Σ F1_i`
- `Weighted-F1 = Σ (support_i / N) * F1_i`

Что это означает в NER:
- `Precision`: насколько “чистые” предсказанные сущности (мало ложных срабатываний).
- `Recall`: сколько истинных сущностей модель смогла найти (мало пропусков).
- `F1`: баланс между precision и recall.
- `Macro-F1`: среднее качество по классам с равным весом (важно при дисбалансе классов).
- `Weighted-F1`: среднее с учетом частоты классов.

## 7. Интерпретация для доклада

- Дообученная `ruBERT-base` показывает высокий и стабильный результат на независимом test-наборе.
- Модель хорошо обобщает на финансовые сущности разных типов.
- Основные остаточные ошибки: короткие аббревиатуры и пограничные случаи между классами.
- Важно подчеркнуть на защите: примеры и метрики получены именно на независимом test (`test_ner_dataset.csv`), а не на train.
